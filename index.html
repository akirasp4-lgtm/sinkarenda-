📝 日報入力の流れ

  1. 操作者（自分の名前）を選択 ※初回のみ、以降は記憶
  2. 作業日を選ぶ（連続する複数日は終了日も指定）
  3. 作業区分を選ぶ ⚠️ 必須・最初に選ぶ（選ぶまで以下の項目が入力できません）
  4. 元請名をプルダウンから選択（なければ ➕ で追加）
  5. 現場名をプルダウンから選ぶ／🔍検索ボックスで絞り込み（最近使った順で並ぶ）。新規は「＋ 新規現場として追加」
  6. 🚗 車両（任意・グローライズのみ・複数選択可）— 同日に他予定で予約済みは選択不可。2 台で行く時は両方の chip を ON
  7. 責任者を選ぶ（その日の現場の責任者）
  8. 班員（責任者以外のメンバー）を選ぶ
  9. 出勤/退勤時間とメモを入力
  10. 必要なら 🏭倉庫 / 🌙夜勤 / 🏖️休み / 📌予定 を選択
  11. 登録するボタンで送信

💡 人工は1日=1.0で固定（休み=0、それ以外=1.0）。1日に複数現場行ったら自動で1/Nに按分されます。

⚠️ 作業区分ゲート 🆕

画面上部に赤い警告バーが出ます: 「最初に『作業区分』を選択してください」。

  • 作業区分を選ぶまで、現場名・メンバー・時刻・モードなど下の入力欄はすべてロック
  • これは 現場名の統一 と 工番の正しい発番 を強制するためのガード
  • 編集モーダルでも同様の動作

作業区分の種類:

  • 現場作業: 通常の現場稼働 → グローライズなら工番が発行される
  • 現調: 現地調査 — 工番なし
  • 着打ち: 着工前の打合せ — 工番なし
  • カギ借用: カギの貸借や立会のみ — 工番なし
  • 材料引取・検品: 材料・道具の搬出入＋検品 — 工番なし
  • 撤去品返却: 撤去物の返却作業 — 工番なし
  • 移動: 前日移動・宿泊など実作業前の移動 — 工番なし
  • 置局: 基地局・アンテナ等の設置作業 — 工番なし
  • 事務所: 事務所での作業・待機 — 工番なし
  • 🏭 倉庫作業: 選ぶと自動的に倉庫モード ON、倉庫タスクが選べる — 工番なし
  • 🏖️ 休み: 選ぶと自動的に休みモード ON、他項目は不要 — 工番なし
  • その他: 上記以外 — 工番なし

集計（人工合計）は全区分を合算。カレンダーでは現場作業以外が黄色いタグで表示されます。

🏷 モードの使い分け

  • 🏭倉庫: 倉庫作業（工番なし、人工1.0は出勤としてカウント）
  • 🌙夜勤: 夜勤（昼勤と独立カウント。詳細は次セクション）
  • 🏖️休み: 休暇・欠勤（人工は0）
  • 📌予定: 未確定の予定（集計・工番から除外）

🆕 休み・倉庫モード時の挙動

  • 🏖️休み / 🏭倉庫 をONにすると 元請・現場・時間・メモ等の入力欄が自動で無効化されます
  • 入力した後にON にすると入力済みの値は自動でクリアされます（操作者・日付・責任者・班員は残ります）
  • 元請名は入力不要になります
  • もう一度同じトグルを押すと解除され、入力欄が再び有効化されます

🆕 🏭倉庫モード時の作業内容選択

  • 🏭倉庫 をONにすると 「今日の倉庫作業」セクションが出現します
  • 選択肢: 🧹清掃 / 📦備品管理 / 🔧工具メンテナンス / 🚚入荷対応 / 📤出荷準備 / ♻️廃材処理
  • 該当する作業を 1 つ以上タップして選択（複数選択可）
  • 選んだ作業はカレンダーに「🏭 清掃、備品管理」のように表示されます
  • 誰が何の倉庫作業をしているか後から振り返れます

🆕 工番が発行されないモード

  • 🏖️休み / 🏭倉庫 / 📌予定 のいずれかがONの場合は工番が発行されません
  • 🌙夜勤は通常通り工番発行対象です

🆕 カレンダー表示

  • 元請名なしの休み・倉庫はカレンダーに「🏖️ 休み」「🏭 倉庫」と表示されます
  • 元請名ありの場合は「🏖️ 〇〇電気」「🏭 〇〇電気」のように先頭にアイコンが付きます

🌙 夜勤モードの使い方

夜から翌朝にかけての作業はこのモードでON。

  1. 作業日: 作業を始める日を選ぶ（翌朝5時に終わる場合は前日）
  2. 🌙夜勤モード をON
  3. 出勤・退勤時間: 実際の時刻をそのまま入力（例 22:00 〜 05:00）

✓ 退勤＜出勤エラーは夜勤モード時は免除されます

✓ 翌日のカレンダー・空き確認にも自動で「⏰前日から」表示（集計には影響なし）

✓ 同日に昼勤+夜勤を別登録すると合計2人工（独立カウント）

❌ よくあるミス: 作業日を翌日にしてしまう / 夜勤モードOFFのまま22:00→05:00入力 / 9-18のまま登録

📱 スマホ便利機能

  • 引き下げて更新: 画面を下に引っ張ると最新データを取り込みます
  • 📤 共有: 予定詳細から LINE・メール等へワンタップで送れます
  • 🎤 音声入力: メモ欄でキーボードのマイクボタンを押すと声で入力できます
  • 📲 ホーム画面に追加: アプリのように起動できます（バナーから／iPhoneは Safari の「共有」→「ホーム画面に追加」）
  • 触覚フィードバック: スワイプ・登録時に軽く振動します（対応端末のみ）
  • スマホ表示: 空き確認・車確認はスマホでは見やすいリスト形式で自動表示

🚗 車両セレクタ 🆕 複数選択対応

予定登録時に、使用する車両を chip ボタンで複数選択できます。

  • 未選択 = 「使用しない」。1 台ならその chip だけ ON、2 台以上で行くなら複数選択
  • 選んだ日に他の予定で既に予約済みの車両はグレーアウト＋「使用中」表示で選べません
  • 連続入力（複数日）の場合は、その期間中いずれかの日で予約済みなら選択不可
  • 編集モーダルでも同じ動作（自分自身のグループは除外して判定）
  • 複数選んだ場合、シート・詳細・共有テキストには「メビウス、ヤリス」のようにカンマ区切りで保存
  • 🏖️休み / 🏭倉庫 をONにすると車両セレクタも自動でロック＆クリア

登録できる車両: ダブルキャブ / ユニック / 高所作業車 / ハイエース（白・シルバー・白2）/ タウンエース / ProBox / ジムニー / クリッパー（シルバー）

🔍 現場名プルダウン＋検索 🆕

元請を選ぶと、その元請に紐付く既存の現場名がプルダウンに自動列挙されます。

  • 並び順は 最近使った順（最終使用日が新しい順）
  • プルダウンの上に 🔍 検索ボックス（部分一致）— 文字を打つと候補が絞り込まれる
  • 新規現場は 「＋ 新規現場として追加」 を選択 → 直接入力欄が出現
  • 新規入力時は 類似する既存現場 が黄色枠でサジェスト → 表記揺れ防止（例: 「○○ビル」と「〇〇ビル新築」を分けないよう促す）
  • 送信時にも似た現場名があれば確認ダイアログが出る

編集モーダルでも同じ動作。会社を切り替えると候補が更新されます。

🔢 工番事業部セレクタ（グローライズのみ）

新規現場を「現場作業」で入力すると「新規現場の工番事業部」セレクタが表示されます。

  • デフォルトは責任者の事業部
  • 初日だけ他事業部の人が責任者になる場合は手動で変更OK
  • 選んだ事業部が工番の頭文字になります（例: ICT-26-001）
  • 工番が発行されないケース: 作業区分が「現場作業」以外 / 🏭倉庫 / 🏖️休み / 📌予定

⚠️ 異常値の警告

  • 退勤 ≤ 出勤 → 送信ブロック（🌙夜勤モード時は免除）

📅 カレンダータブ

月単位で予定をカレンダー表示。

  • 日付をタップ → 日別モーダル（現場名+メンバーの最小表示）
  • 予定カードをタップ → 詳細フルスクリーン画面へ
  • 該当する モードアイコン（🏭🌙🏖️📌）がカード末尾に表示
  • 日付跨ぎ予定は翌日に「⏰前日から」のラベル付きで自動表示（集計影響なし）
  • PCで開くとカレンダーが大きく中央表示

📖 予定詳細フルスクリーン画面

日別モーダルでカードをタップで開きます。

  • 表示項目: 現場名/期間/モードバッジ/作業区分/メンバー/人工/会社/工番/メモ/最終更新者
  • メモ内のURL（http(s)://）はタップ可能なリンクに自動変換
  • 左上「←」または右スワイプで戻る
  • 左スワイプで同じ日の次の予定にループ
  • 右上 🗑️ → 削除 / 下部 コピー・編集

編集・削除・コピーはすべて詳細画面に集約（日別モーダルにはボタンなし）

👆 スワイプ操作

  • カレンダー画面: 左→次月 / 右→前月
  • 日別モーダル: 左→翌日 / 右→前日
  • 空き確認の週テーブル: 左→次週 / 右→前週
  • 予定詳細画面: 左→次の予定 / 右→戻る

👥 空き確認タブ

指定週の全職人の空き状況を一覧表示。休み・倉庫は色分け表示。左右スワイプで前週/次週切替。

🚗 車確認タブ（グローライズのみ） 🆕

週次の 車両×日付マトリクス で予約状況を一目で確認できます。

  • 空きは「○」、使用中は責任者名と行先が表示される
  • 週移動ボタン（◀▶）または左右スワイプで前週／翌週に移動
  • 他予定で予約済みの車両は新規予定登録時にプルダウンでグレーアウトされる（ダブルブッキング防止）

🏗️ 現場管理タブ

既存の現場別に登録内容をまとめて確認・編集。複数日まとめて修正する「一括編集」も可能。

  • 元請名 + 月で絞り込み可能（月は元請の右側、デフォルトは「全期間」）
  • 月を選ぶとその月の現場リスト・日程一覧だけが表示される
  • チェックボックスで複数日選択 → 一括編集で時間・元請・責任者・メンバー・車両等をまとめて変更
  • 編集保存時、メンバーが他の予定とぶつかる場合は被り警告が出ます

🆘 困ったら

  • 入力が反映されない → 「現在他の人が更新中」が出ていたら数秒待って再送信
  • 間違えた日報を消したい → 該当日タップ → 予定カードタップ → 詳細画面右上 🗑️
  • 予定を実績に変更 → 編集画面で 📌予定 を解除して保存
  • 会社が違って表示される → 「会社を選択してください」モーダルで自分の会社をタップ
  • 夜勤予定が翌日にも出る → 仕様通り。集計は元の日にだけ計上されます
