🔑 基本

PIN 8800 で入場。右上の 🔒ロック で一時退出。

画面上部の会社バーで集計対象を切替（全社 or 各社）。

📊 事務タブの使い方

  1. 月別集計: 月を選ぶと職人別の出勤日数・人工合計が表示
  2. Excelでダウンロード: 日報・マスタ・集計・操作ログを xlsx で出力（色・罫線そのまま）
  3. 期間指定でExcel出力: 開始日〜終了日の職人×日付マトリクスを Excel で（合計に =SUM 関数入り）
  4. 職人を管理: 氏名・会社・事業部・単価（日当）を登録/編集
  5. 元請を管理: 元請リストの追加/削除
  6. 集計を更新: 全集計シートを一括再生成（毎朝6時も自動）
  7. データアーカイブ: 3ヶ月以上前を退避（毎月1日3時も自動）
  8. 工番を修正する: 事業部変更（金額の入力はGR管理画面📊経営タブへ）

📥 Excel（xlsx）ダウンロード 🆕

CSV から完全に移行し、Excel ファイルで出力されるようになりました。

  • 色・罫線・フォントがそのまま Excel で開ける
  • 月別確認表・期間集計の 合計列・合計行に =SUM(...) 関数が入る → Excel で値を変えれば合計が自動再計算
  • 開始日／終了日を入力すると、日報データ・アーカイブは作業日列で絞り込まれてダウンロードされる（他のシートは全件）
  • ファイル名: シート名_開始_終了.xlsx 形式

📊 期間指定でExcel出力（職人×日付マトリクス）

  • 開始日・終了日を必ず両方指定して押す
  • 会社バーで選んだ会社（全社可）で絞り込み
  • 月別確認表と同じ見た目（タイトル黄・ヘッダ灰・土日色・罫線）で出力
  • 各行の合計列、合計行の各日と総合計が SUM 関数になっているので、Excel 側で人工を編集すれば自動で再計算される
  • 「月全部入って合計がズレる」「期間外を手で削除して再計算する」手作業がなくなる

🔧 工番修正モーダル

現場マスタの全現場が一覧表示されます。各現場で:

  • 🔍 上部の検索ボックスで 元請名・現場名・工番・責任者 を横断検索できます
  • 事業部を変更 → 「工番更新」で新事業部×年度の次連番で再発番（旧工番は欠番）
  • 責任者の事業部が参考表示されるので、選び直しの判断に使える
  • 💡 売上などの金額入力は GR管理画面の📊経営タブ に一本化しました（このモーダルの売上欄は非表示）

🧹 おかしい工番をクリア

事務タブの赤いボタン。休み・倉庫・予定モードや「現場作業以外」のレコードに残っている 工番・事業部 を一括クリアします。

  • 仕様変更以前に登録された「休み なのに工番がついている」レコードを清掃
  • 新規登録時は既に空のまま保存されているため、通常は1回実行すれば十分
  • クリア後は 「集計を更新」 で集計シートを再計算してください

🔀 元請名をマージ

事務タブの青いボタン。同じ会社が違う名前で登録されてしまった場合に、片方を残してもう片方のレコードを統合します。

  • 例: 「グローライズ」と「グローライズ自社」を「グローライズ自社」に統合
  • 統合する元請（消える方）と 残す元請（こちらに統一）を選んで実行
  • 日報・アーカイブ・現場マスタ・元請マスタ 全部を一括書き換え
  • 取り消し不可なので、本当に同じ元請の重複登録か確認してから実行
  • 影響範囲（何件書き換わるか）はプレビューで確認できます

🏢 現場マスタの管理 🆕

現場（工事案件）が増えてきた時の整理ツール。3 種類あり目的別に使い分けます。

🔀 現場名マージ（表記揺れの統合）

  • 例: 「○○ビル」と「○○ビル新築工事」のように同じ現場が違う名前で登録されてしまった時
  • 現場管理タブ → 該当現場 → 編集 → 「他の現場名にマージ」
  • どっちに合わせるか選択する UI が出る（A の名前にする／B の名前にする）
  • 日報・アーカイブ・現場マスタを 一括書き換え。工番は影響なし
  • 取り消し不可

🗑️ 現場の削除

  • 現場管理タブの現場行に 🗑️ 削除アイコン。間違って登録した現場を完全に消す
  • 条件: 日報・アーカイブに参照なし＋売上未入力の現場のみ削除可
  • 条件を満たさない時は削除不可。代わりに マージ or 完了フラグ を案内

✅ 完了フラグ（プルダウン非表示）

  • 終わった工事を 新規入力時のプルダウンから隠す 機能。データは残るので集計・粗利は維持
  • 現場管理の一覧 → ステータスのプルダウン（見積中／受注／準備中／施工中／残工事／完工／延期／中止）
  • 権限: その現場の 責任者 または 管理者 のみ操作可
  • いつでも別のステータスに変えられる。完工・中止を選ぶと現場名プルダウンから外れる
  • 工番・売上・過去データは完了後も保持される（参照は可能）

💰 粗利・お金の管理について

お金（受注金額・原価・粗利・請求日・入金日）の管理は GR管理画面の「📊経営」タブ に一本化しました（2026-06-11）。このアプリでは入力しません。

※スプレッドシートの「事業部別按分」シート（人工×単価の自動計算）は現在休止中。今入っている数字はテストの残骸なので参考にしないこと。職人マスタの単価は給料・人工管理用としてこのアプリに残ります。

📋 スプレッドシートのシート

  • データ: 日報データ / アーカイブ / 職人マスタ / 元請マスタ / 現場マスタ
  • 集計: 会社別集計 / 月別集計 / 月別確認表 / 元請別請求集計 / 元請別請求集計_フィルタ用 / 事業部別按分
  • 運用: 操作ログ（誰がいつ何を変更したか自動記録）

元請別請求集計_フィルタ用: Excel オートフィルタ用のフラット構造版（月・会社・現場・名前 + 日別人工 + 合計）。事務員が請求用に絞り込みたい時に使う

⚠ 集計シートは手動で書き込まない（次回集計で消える）

📱 スマホ便利機能

  • 引き下げて更新: 画面を下に引っ張って最新データを取得
  • 📤 共有: 予定詳細から LINE・メール等へ送信
  • 🎤 音声入力: メモ欄でキーボードのマイクから音声入力
  • 📲 ホーム画面追加: アプリのように起動（iPhone は Safari「共有」→「ホーム画面に追加」）
  • 触覚フィードバック: スワイプ・登録時に軽く振動（対応端末のみ）
  • スマホ表示: 空き確認・車確認は自動でリスト形式に切替

🚗 車両セレクタ 🆕 複数選択対応

予定登録時に、使用する車両を chip ボタンで複数選択できます。

  • 未選択 = 「使用しない」。1 台ならその chip だけ ON、2 台以上で行くなら複数選択
  • 選んだ日に他の予定で既に予約済みの車両はグレーアウト＋「使用中」表示で選択不可
  • 連続入力（複数日）の場合は、その期間中いずれかの日で予約済みなら選択不可
  • 編集モーダルでも同じ動作（自分自身のグループは除外して判定）
  • 複数選んだ場合、シート・詳細・共有テキストには「メビウス、ヤリス」のようにカンマ区切りで保存
  • 🏖️休み / 🏭倉庫 をONにすると車両セレクタも自動ロック＆クリア

登録できる車両: ダブルキャブ / ユニック / 高所作業車 / ハイエース（白・シルバー・白2）/ タウンエース / ProBox / ジムニー / クリッパー（シルバー）

🌙 夜勤モード（職人画面と共通）

  1. 作業日は作業を始める日を選ぶ（翌朝5時に終わる場合は前日）
  2. 🌙夜勤モードをON、出勤・退勤を実時刻で入力（例 22:00 〜 05:00）

退勤＜出勤エラーは夜勤モード時のみ免除。翌日のカレンダー・空き確認に「⏰前日から」表示が自動で出ますが、集計には影響しません。

🆕 休み・倉庫モードの仕様

🏖️休み / 🏭倉庫 トグルON時の挙動

  • 元請・現場・作業区分・出勤/退勤・メモ等の入力欄が自動で無効化される
  • すでに入力されている値は自動でクリアされる
  • 元請名は入力不要（バリデーションをスキップ）
  • 操作者・日付・責任者・班員は引き続き入力可能
  • もう一度同じトグルを押すと解除され、入力欄が再び有効化される

工番が発行されないモード

  • 🏖️休み / 🏭倉庫 / 📌予定 のいずれかがONの場合は工番が発行されない
  • 🌙夜勤は通常通り工番発行対象

カレンダー表示

  • 元請名なしの休み・倉庫は「🏖️ 休み」「🏭 倉庫」と表示
  • 元請名ありは「🏖️ 〇〇電気」「🏭 〇〇電気」のようにアイコン付き表示
  • 倉庫モードで作業内容を選んだ場合は「🏭 清掃、備品管理」のようにタスク名が表示

🆕 倉庫モードの作業内容選択（必須）

  • 🏭倉庫 ON にすると「今日の倉庫作業」セクションが出現
  • 選択肢: 🧹清掃 / 📦備品管理 / 🔧工具メンテナンス / 🚚入荷対応 / 📤出荷準備 / ♻️廃材処理
  • 1 つ以上必須。複数選択可。保存時に 現場名 列にカンマ区切りで保存される
  • 編集時もチェック状態が復元される
  • 誰がいつ何の倉庫作業をやったか後から振り返れる（藤木さんなどの動きを可視化する目的）

シート集計での扱い

  • 休み: 人工=0、出勤日数にもカウントされない
  • 倉庫: 人工=1.0、出勤日数に+1（通常勤務と同じカウント）
  • 倉庫レコードに元請名がない場合、元請別請求集計・事業部別按分には載らない（工番なし・元請なしのため）

📊 1日複数現場の按分ルール（A案）

1人が同じ日に複数現場へ行ったら、自動で 1人工を 1/N に按分。

  • 昼A + 昼B → 各 0.5（合計 1.0）
  • 3現場 → 各 1/3
  • 昼A + 夜B → A=1.0、B=1.0（昼夜は別カウント）

影響シート: 元請別請求集計 / 事業部別按分。月別確認表は1日1人工で頭打ち。

🏷 作業区分（必須・ゲート）

登録／編集モーダルでは 作業区分を最初に選択するまで他の項目が入力できません（赤い警告バー表示）。表記揺れ防止と工番の正しい発番のためのガード。

  • 区分: 現場作業 / 現調 / 着打ち / カギ借用 / 材料引取・検品 / 撤去品返却 / 移動 / 置局 / 事務所 / 倉庫作業 / 休み / その他
  • 🏭 倉庫作業を選ぶと自動で倉庫モードに切替、倉庫タスク選択UIが出現（工番なし）
  • 🏖️ 休みを選ぶと自動で休みモードに切替（工番なし、人工0）
  • グローライズの工番は「現場作業」のみ発行（他の区分・休み・倉庫・予定では工番なし）
  • 集計上は全区分を合算。詳細画面・月別確認表では区分が見えるよう表示

🔍 現場名プルダウン＋検索 🆕

元請を選ぶと、その元請に紐付く既存の現場名がプルダウンに表示されます。

  • 並び順は 最近使った順（最終使用日の降順）
  • プルダウン上の 🔍 検索ボックスで部分一致絞り込み — 通常時は「(N件・最近順)」、絞込中は「(ヒット/全件)」表示
  • 新規現場は 「＋ 新規現場として追加」 を選択 → 直接入力欄が出現
  • 新規入力時は類似する既存現場が黄色枠でサジェスト（表記揺れ防止）
  • 編集モーダルでも同じ動作。元請を切り替えると候補が更新

📅 カレンダー / 詳細画面 / スワイプ

  • 日付タップ → 日別モーダル（現場名+メンバー+モードアイコンの最小表示）
  • 予定タップ → 詳細フルスクリーン（編集・削除・コピー集約）
  • メモ内URLは自動でタップ可能リンクに変換
  • 横スワイプ: 月切替/前後日/前後週/詳細前後

🏗️ 現場管理タブ

  • 元請名 + 月で絞り込み可能（月は元請の右側、デフォルトは「全期間」）
  • 月を選ぶとその月の現場リスト・日程一覧だけが表示される
  • チェックボックスで複数日選択 → 一括編集で時間・元請・責任者・メンバー・車両等をまとめて変更
  • 編集保存時、メンバーが他の予定とぶつかる場合は被り警告が出ます

🆘 困ったら

  • 工番が空欄 → 責任者の事業部未設定。職人管理で割当
  • 粗利がマイナス → 売上未入力 or 単価が高すぎる可能性
  • 原価が0 → 職人の単価が未設定
  • 起動が遅い → アーカイブを実行（3ヶ月以前を退避）
  • 事業部別按分で「不明」 → 職人マスタで事業部を割当 or 工番修正で現場の事業部確定
  • 現場マスタに使ってない現場名が残る → 集計実行時に自動掃除（売上未入力＆日報参照なし）。データを残したい場合は ✅完了フラグ でプルダウンから隠す
工番事業部の修正

各現場の事業部を選び直して「更新」で反映。新事業部×年度の次連番で新工番を発番し、現場マスタ＋日報データ＋アーカイブを一括更新します。旧工番は欠番として残ります。

💡 金額（受注金額・原価・請求日など）の入力は GR管理画面の「📊経営」タブ に一本化しました。ここでは入力しません。

🔀 元請名をマージ

「統合する元請」のレコードを「残す元請」の名前に書き換えます。日報・アーカイブ・現場マスタ・元請マスタ全部一括で書き換えます。この操作は取り消せません。

🔀 現場名をマージ

同じ元請の中で表記揺れになっている現場名を統合します。日報・アーカイブ・現場マスタを一括書き換え。統合先に工番がある場合は日報の工番もそちらに統一されます。この操作は取り消せません。
